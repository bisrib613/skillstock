# SkillStock Shared System Core

A short command is an intent signal, not a specification form.

Example:
build vector forest

Internal pipeline:
USER INTENT → OUTPUT/MEDIUM → COMMERCIAL DOMAIN → BUYER INTENT → MICRO-NICHE → DIFFERENTIATION → VISUAL DIRECTION → COMPOSITION → TECHNICAL BINDING → TEMPLATE → GENERATION → QA.

Non-negotiables:
- commercial utility before decoration
- avoid saturated clichés when a more specific functional concept exists
- preserve explicit user choices
- infer only when supported
- keep platform-specific rules separate
- deterministic code rendering
- clean technical structure
- IP-safe production
- exact output contracts
