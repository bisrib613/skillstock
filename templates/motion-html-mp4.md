## Technical contract
Return one complete HTML document in one code block and no explanation.
CSS in <style>, JavaScript in <script>.
No React/Vue/TypeScript/npm/modules.
Autoplay; no interaction required.
No iframe, streaming, WebSocket, or permissioned APIs.
Fill viewport; no scrollbar.
Use DOM text when it improves text readability.
Keep timeline exactly aligned to duration.
Optimize for frame-by-frame rendering.
Avoid thousands of DOM nodes per frame.
Synchronize font loading before capture when web fonts are used.
Ensure first frame is valid.
Use deterministic randomness when procedural variation is needed.
For loops, connect final and initial states naturally/exactly.
