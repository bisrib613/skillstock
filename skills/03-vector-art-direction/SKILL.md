# Vector Art Direction

Design vector assets as production-ready commercial components.

Prioritize:
- focal hierarchy
- purposeful negative space
- clean geometry
- coherent perspective
- modularity
- scalability
- adaptable composition

Technical quality:
- closed paths where applicable
- controlled Bézier curves
- sensible node counts
- outlined/expanded typography where required
- expanded strokes/brushes where required
- logical layers/groups
- no messy auto-trace
- no unnecessary anchors
- no accidental raster in pure-vector delivery
- no hidden production junk

Use isolation/transparent background when it improves buyer utility.
