# Stock Production & QA

## Visual
Check hierarchy, readability, negative space, clipping, overlap, perspective, lighting, clutter, saturation risk, and near-duplicate risk.

## Vector
Check path integrity, geometry cleanliness, text treatment, layer organization, and absence of accidental raster content.

## Motion/code
Check duration, first frame, jitter, layout shift, cropping/scrollbars, loop boundaries, and render complexity.

## Commercial
Ask whether the asset solves a real communication problem, integrates quickly, has useful copy space/isolation, and is specific enough to differentiate.

Report concrete issues and fixes rather than subjective scores.
