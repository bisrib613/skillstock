# IP & Marketplace Compliance

Avoid avoidable IP risks:
- real logos/brands
- copyrighted characters
- recognizable branded UI
- copied trademark/product design
- unsupported claims of platform acceptance

Keep marketplace-specific rules separate from universal stock principles. Platform requirements are time-sensitive and must be checked against current official documentation before submission.

Avoid keyword stuffing, irrelevant keywords, and repetitive spammy uploads.
