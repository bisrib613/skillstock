# Motion Art Direction — Prompt Specification

## Purpose
Translate commercial utility into motion that communicates a process, state, interaction, transformation, or useful visual system.

## Research-derived motion utility
Prioritize stock-useful formats such as:
- isolated/alpha-capable transitions and elements;
- dashboard/UI overlays;
- seamless background/data loops;
- explainer B-roll components;
- concise promotional motion.

Research places commercial motion in a 5–15 second range. For this project, actual duration is chosen only by the active project rules and user request; never copy a duration from a research example.

## Motion stack
For each meaningful scene/state define:
1. purpose;
2. entry state;
3. primary action;
4. secondary/supporting movement;
5. transition;
6. exit state;
7. timing;
8. easing/velocity character;
9. settling/hold;
10. loop relationship when applicable.

## Premium motion language
Research contrasts robotic linear interpolation with custom cubic-bezier/spring behavior, secondary motion, and micro-animation.
Use acceleration/deceleration, anticipation, settling, restrained secondary motion, and readable staging.
Linear motion is acceptable only when constant speed is functionally appropriate.

## Instant comprehension
Motion must communicate the intended state quickly. Do not bury the main action under particles, camera effects, excessive transitions, or decorative motion.

## Loop
For loops, the final state must return deterministically to the initial state. Match position, rotation, scale, phase, and other persistent procedural variables.

## Output
Return a concrete motion system with state purpose, timing, movement hierarchy, easing behavior, transitions, and commercial utility.
