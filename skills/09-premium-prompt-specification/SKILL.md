# Premium Production Prompt Specification — Layer 1

## Purpose
Translate research-derived commercial intelligence into an implementation-ready production specification.

## Commercial foundation
Research ties premium value to functional design and technical usability: the buyer should be able to integrate the asset with minimal reconstruction.

Specify when relevant:
1. commercial purpose/communication goal;
2. conceptual situation;
3. visual system;
4. subject/state hierarchy;
5. composition/framing;
6. background/environment support;
7. scene/state architecture;
8. full timeline;
9. primary motion;
10. secondary/micro motion;
11. transitions;
12. keyframe checkpoints;
13. easing/velocity character;
14. palette/color roles;
15. typography behavior;
16. camera/viewport;
17. loop strategy;
18. technical production direction;
19. IP/asset restrictions.

## Premium composition
Use hierarchy, useful negative space, clear focal point, safe margins, relative scale, and depth.
The research's 40–50% copy-space pattern is use-case-dependent, not universal.

## Premium visual system
Use controlled palettes and functional color roles. Translate style labels into shape, surface, line, depth, lighting, and texture behavior.

## Premium motion
Favor non-linear timing, deliberate acceleration/deceleration, settling, secondary motion, micro-animation, and meaningful state changes over mechanical linear movement.

## Production-ready utility
Where relevant, design for isolated components, transparent/alpha utility, dashboard overlays, seamless loops, presentation modules, reusable diagrams, or other buyer workflows identified by the research.

## Timeline
When duration is known/inferred, cover 0.00s through the exact endpoint. Use meaningful ranges, holds, transitions, and state changes. Do not add arbitrary timestamps merely to appear detailed.

## Technical adaptation
For Canvas/JavaScript, express implementation through responsive coordinates, deterministic time-based state, render-safe drawing, stable frame behavior, and loop-safe logic. Do not copy HTML/CSS implementation details unless the source template requires them.

## Restraint
Do not add effects, particles, camera moves, text, or numeric parameters without a communication, polish, commercial, or implementation reason.
