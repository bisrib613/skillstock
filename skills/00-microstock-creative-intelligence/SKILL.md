# Microstock Creative Intelligence — Layer 1

## Purpose

Turn a minimal user request into a commercially informed creative direction that can populate a high-detail production prompt.

This is the decision layer, not the final prose template and not the downstream generator.

## Mandatory reasoning order

1. Parse the user's requested output type and explicit constraints.
2. Identify the broad commercial category.
3. Identify the likely buyer and real use case.
4. Classify the opportunity as evergreen, current/emerging, seasonal, saturated, or mixed when the research supports that distinction.
5. Resolve the broad topic into one primary useful niche/micro-niche.
6. Define the communication problem the asset should solve.
7. Select a differentiated visual concept that communicates the problem quickly.
8. Select visual style and art direction appropriate to the use case.
9. Design the composition and subject hierarchy.
10. Define scene/state structure and motion direction when the output is animated.
11. Bind the technical defaults and constraints from the source template.
12. Hand the resolved direction to the Prompt Template Builder.
13. Run Prompt QA.

## Commercial intelligence

Use the research as decision support, not as a catalog to copy mechanically.

Prioritize:
commercial demand → buyer utility → differentiation → longevity → production feasibility.

Demand signals and trend findings are evidence. Creative choices derived from them are inference. Do not present inference as measured sales data.

## Short-input interpretation

For commands such as `build prompt code to mp4 passkey` or `build prompt vector forest`, infer the missing commercial context from the skills and research.

Do not make the user repeat information that can be responsibly inferred.

## Anti-generic decision

When the broad theme maps to a saturated metaphor, choose a more functional representation when supported by the research.

Do not simply decorate a cliché to make it appear different.

## Premium depth requirement

The resolved direction must be detailed enough to drive a professional prompt, including where relevant:
- concept and communication goal
- visual hierarchy
- spatial arrangement
- object/state relationships
- scene structure
- exact timeline
- motion behavior
- easing
- color roles
- camera/framing
- loop behavior
- technical constraints

## Boundary

This skill never generates JavaScript, HTML, CSS, SVG code, MP4, or other downstream assets.

Its output is structured creative intelligence for the prompt-builder layer.

## Clarification

Ask only when an unresolved ambiguity materially changes the requested prompt and cannot be safely inferred.

## Guardrails

Do not fabricate marketplace sales data, search-rank weights, moderation thresholds, or guaranteed outcomes.
