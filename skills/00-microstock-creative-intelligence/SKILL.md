# Microstock Creative Intelligence — Layer 1

## Purpose
Turn a minimal user request into a commercially informed creative direction that can populate a high-detail production prompt.

This is the decision layer, not the final prose template and not the downstream generator.

## Orchestration
Use the skills as a pipeline rather than selecting one skill in isolation.

Commercial request → Market & Buyer Intent → Commercial Concept & Micro-Niche → Visual Direction → Motion Scene Engineering when animated → Programmatic Rendering when code-rendered → Prompt Template Builder → Prompt QA.

## Mandatory reasoning
1. Parse requested output type and explicit constraints.
2. Identify broad commercial category.
3. Identify likely buyer and practical use case.
4. Classify the opportunity using supported research signals.
5. Resolve one primary niche/micro-niche.
6. Define the communication problem or message.
7. Select a differentiated visual concept.
8. Select style and art direction appropriate to the use case.
9. Define composition, hierarchy, copy space/isolation, framing, and supporting elements when relevant.
10. For animation, define scene/state structure, timeline, keyframes, transitions, motion language, and loop behavior.
11. Bind technical defaults and constraints from the source template.
12. Assemble the complete prompt without executing it.
13. Run Prompt QA.

## Commercial intelligence
Use research as decision support, not as a list to copy.

Prioritize: commercial demand → buyer utility → differentiation → longevity → production feasibility.

Separate measured evidence from creative inference and unknowns. Never fabricate sales figures or marketplace certainty.

## Short-input interpretation
For commands such as build prompt code to mp4 passkey or build prompt vector forest, infer missing commercial context from the skills and research.

Do not ask the user for information that can be responsibly inferred.

## Anti-generic decision
When research indicates a saturated metaphor, prefer a functional representation of the actual process, system, or use case.

Do not make a cliché appear different merely by changing colors, particles, or camera angle.

## Premium depth
The creative direction must be detailed enough to drive a professional production prompt: concept, communication goal, visual states, hierarchy, spatial arrangement, scene/timeline when relevant, motion behavior, easing, palette roles, framing, loop behavior, and technical constraints.

## Boundary
This skill never generates JavaScript, HTML, CSS, SVG code, MP4, or final visual assets.
