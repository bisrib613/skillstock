# Commercial Concept & Micro-Niche

## Purpose
Turn a broad theme into one specific, differentiated, commercially useful concept after the Demand Gate.

## Concept chain
Broad theme → market category → niche → micro-niche → buyer problem → communication goal → visual system → variation depth.

## Selection rules
Prefer concepts that naturally explain:
- a process or workflow;
- a system/infrastructure;
- a comparison;
- monitoring/data;
- verification/status;
- transformation;
- a functional interface;
- an operational environment.

Avoid concepts whose only value is “looks attractive”.

## Research micro-niche model
The research selected micro-niches where four conditions meet:
1. real industry demand;
2. buyer utility;
3. lower saturation;
4. sufficient subject/variation depth.

Examples include:
- Passkey/passwordless FIDO2 security flow;
- Scope 3 ESG / industrial carbon accounting;
- autonomous cold-chain pharmaceutical logistics;
- telehealth/remote patient monitoring.

Use these as demonstrated patterns, not mandatory outputs.

## Functional differentiation
When a theme has a saturated literal metaphor, represent the actual function.
Examples from the research:
- generic forest scene → managed forest/conservation/carbon-monitoring context;
- generic corporate infographic → modular operational metrics/process visualization;
- spinning padlock → actual passwordless verification flow;
- simple moving cars → mobility-service interaction with map, reservation, EV context.

Do not create differentiation through color swaps, particles, glows, or camera changes alone.

## Variation depth
Before finalizing, check whether the concept can support meaningful variants:
process states, success/failure, before/after, comparisons, modules, environments, data states, object variants, or system states.
Variation must remain meaningfully different; do not encourage near-duplicate spam.

## Output
Return one primary micro-niche and one coherent commercial concept, with buyer/use case, communication goal, differentiation, and useful variation directions.
